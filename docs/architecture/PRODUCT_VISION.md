# Product Vision

ARTSA answers one security question: **may this agent perform this action on
this enterprise resource now?** It combines runtime content screening with
identity, tool, repository and policy context, then produces a redacted,
auditable decision.

The v1 buyer is the security team. The v1 workflow is MCP-to-GitHub Cloud,
customer-VPC deployment, a least-privilege GitHub App, digest-only evidence,
and human approval before risky writes. ARTSA does not claim broad SaaS
discovery, autonomous remediation, full payload retention, or measured model
accuracy until those capabilities are independently verified.
